# Awesome Changelogs [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of outstanding changelogs and tools that make release communication better.

Great changelogs help users understand what changed, why it matters, and what to do next. This list celebrates projects that do it well and tools that make it easier.

## Exemplary Changelogs

Changelogs worth studying -- clear writing, consistent format, user-focused.

- [Tailwind CSS](https://tailwindcss.com/blog) - Every release is a mini blog post explaining the "why" behind changes.
- [Laravel](https://laravel.com/docs/releases) - Versioned release notes with upgrade guides and migration steps.
- [Stripe API](https://stripe.com/docs/changelog) - Developer-focused changelog with breaking change warnings and code examples.
- [Linear](https://linear.app/changelog) - Beautiful visual changelog with screenshots and categorized updates.
- [Raycast](https://www.raycast.com/changelog) - Clean, scannable updates with clear feature descriptions.
- [Supabase](https://supabase.com/changelog) - Weekly shipping updates with demos, architecture deep-dives, and Launch Week recaps.
- [Clerk](https://clerk.com/changelog) - SDK-level changelog with migration guides for breaking changes.
- [Resend](https://resend.com/changelog) - Minimal, focused changelog that highlights what matters.
- [Vercel](https://vercel.com/changelog) - Frequent updates with visual previews and clear categorization.
- [PostHog](https://posthog.com/changelog) - Detailed feature announcements with context on user requests.
- [Astro](https://astro.build/blog/) - Detailed release posts with before/after comparisons, benchmarks, and migration guides.
- [Cal.com](https://cal.com/changelog) - Open-source project with public, well-structured release notes.

## Changelog Tools

### Generators

- [conventional-changelog](https://github.com/conventional-changelog/conventional-changelog) - Generate changelogs from conventional commit messages.
- [auto-changelog](https://github.com/cookpete/auto-changelog) - Command-line tool for generating changelogs from Git tags and commit history.
- [git-cliff](https://github.com/orhun/git-cliff) - Highly customizable changelog generator written in Rust.
- [github-changelog-generator](https://github.com/github-changelog-generator/github-changelog-generator) - Generate changelogs from GitHub issues and pull requests.
- [changesets](https://github.com/changesets/changesets) - Manage versioning and changelogs for multi-package repos.
- [release-please](https://github.com/googleapis/release-please) - Automates releases based on conventional commits with changelog generation.
- [lerna-changelog](https://github.com/lerna/lerna-changelog) - Generate changelogs for Lerna monorepos from merged PRs.
- [semantic-release](https://github.com/semantic-release/semantic-release) - Fully automated version management and changelog generation based on commit messages.

### CLI Tools

- [changelogdev-cli](https://www.npmjs.com/package/changelogdev-cli) - Push changelog entries from your terminal or CI pipeline.
- [changie](https://github.com/miniscruff/changie) - Automated changelog tool for preparing releases with fragments.
- [towncrier](https://github.com/twisted/towncrier) - Build changelogs from news fragment files (Python ecosystem).

### Widgets & Embeds

- [changelogdev-widget](https://www.npmjs.com/package/changelogdev-widget) - Embeddable changelog widget for any website. Show updates in-app.
- [headway](https://headwayapp.co/widget) - Changelog widget with notification badges.

## Hosted Changelog Services

- [Changelog.dev](https://www.changelogdev.com) - Beautiful hosted changelogs with API, CLI, widget, and GitHub Action. Free tier available.
- [Headway](https://headwayapp.co) - Changelog as a service with widget and public page.
- [Beamer](https://www.getbeamer.com) - In-app changelog and notification center.
- [AnnounceKit](https://announcekit.app) - Changelog pages with in-app widgets and analytics.
- [Released](https://released.so) - AI-powered release notes from your project management tool.
- [Canny](https://canny.io) - Feature request tracking with built-in changelog.
- [LaunchNotes](https://www.launchnotes.com) - Release communication platform for product teams.
- [LogSnag](https://logsnag.com) - Event tracking with public changelog feature.

## GitHub Actions

- [changelog-action](https://github.com/NikitaDmitrieff/changelog-action) - Automatically create changelog entries from GitHub releases.
- [release-drafter](https://github.com/release-drafter/release-drafter) - Draft release notes as PRs are merged.
- [changelog-ci](https://github.com/saadmk11/changelog-ci) - Automatically generate changelogs on pull requests.

## Changelog Standards

- [Keep a Changelog](https://keepachangelog.com) - The definitive guide to writing good changelogs.
- [Conventional Commits](https://www.conventionalcommits.org) - A specification for structured commit messages that feed changelog generation.
- [Semantic Versioning](https://semver.org) - The versioning scheme that underpins meaningful changelogs.
