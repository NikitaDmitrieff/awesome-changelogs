# Contributing to Awesome Changelogs

Thank you for contributing! Here's how to help.

## Adding a Changelog or Tool

1. Fork this repo
2. Add your item to the appropriate section in `README.md`
3. Use the format: `- [Name](URL) - Brief description ending with a period.`
4. Keep descriptions concise (one sentence)
5. Submit a pull request

## What qualifies?

### Exemplary Changelogs
- Must be publicly accessible
- Demonstrates clear, user-focused writing
- Consistent format across releases
- Actively maintained

### Tools & Services
- Must be actively maintained (commits in the last 6 months)
- Should have documentation
- Open-source tools preferred but not required

## What doesn't qualify?
- Internal or private changelogs
- Abandoned projects (no updates in 12+ months)
- Tools that only generate git logs (not formatted changelogs)

## Guidelines

- Alphabetical order within sections
- No promotional language -- describe what it does, not why it's great
- Check for duplicates before submitting
- One item per pull request preferred
